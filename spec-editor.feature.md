# Spec Editor

## Create New Spec @v1 [proposed]

Add scenario.
This opens the editor for the new spec.
The new spec editor dialog has a title for the user to fill in.
The new spec starts in draft mode.
The draft spec is persisted in Automerge.
The user can use Delete as long as the spec is in draft mode or proposed mode.
The escape key or the close-editor widget will leave the scenario in its autosaved state. A help note at the bottom of the dialog, like the Settings dialog, says to use the Esc key or the close-editor widget.
Two buttons available: "Propose" and "Publish".
