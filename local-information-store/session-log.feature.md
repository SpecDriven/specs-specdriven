# session log

## Session Log Format @v1 [proposed]

SpecDriven App will store logs of coding sessions.
A coding session log includes the following information.
- The name of the coding session
- The LLM model used for the session
- The time taken for the session from start to finish, as seen by SpecDriven
- The cost in tokens reported by the LLM coding agent, separated by 
- The cost in money reported by the coding agent.
