# Which SDD will win ?

**Author:** David Vydra

**Date:** 2026-10-17

**Kind:** Observation

responding to https://www.linkedin.com/posts/valentinajemuovic_spec-driven-development-when-ai-writes-the-share-7516752379958980608-as03/?utm_source=share&utm_medium=member_desktop&rcm=ACoAAAABVcgBkX-l5A6YvINj1jYKbSqdF_2DzHg

I've been a promoter of test-driven development for well over 20 years. What I've learned in the process is that while the industry agreed that tests are mandatory, writing tests before code was a "road less travelled" for the vast majority of developers. Furthermore, the industry split between practitioners who have learned how to write useful and impactful tests and those who only cared about the code coverage number in order to merge their PR.

I see the same dynamics play out in spec-driven development as we collectively try to figure out what that practice entails. There is mounting evidence that most developers prefer "chat-oriented development" -- that is they plan with their agent in a conversational style and then let it generate the code and tests. Needless to say that hitting 90% code coverage is assumed in this process.
