# Specification import from existing documents

It is often advantageous to generate an initial set of specification from existing documents with the help of an AI agent.

These documents maybe web-based such as Aha!, Jira, or Confluence Wiki or maybe files we can read on the filesystem or download via a link.

Given that the amount of information maybe substantial - we want to employ an 'orchestrator' strategy.

We want to give the user an option of which strategy they want to use.
