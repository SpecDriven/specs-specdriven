# Support Event Modeling

**Assigned:** David

Event Modeling is a specification technique that has been growing in popularity in the last few years.

It was originated by Adam Dimitruk. Martin Dilger wote a book on it - https://www.eventsourcingbook.com/ and created https://github.com/dilgerma/event-modeling-spec to capture models.

We should support Event Modeling along side "traditional" BDD-style feature files.

**Status (2026-09-23).** Shipped as the Models tab, and since SpecDriven
0.1.87 a plugin rather than part of the app: `models` in the
SpecDriven/plugins marketplace, installed from Settings → Plugins. See
[plugin architecture](plugin-architecture.md).
